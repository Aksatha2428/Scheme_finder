# Government Scheme Finder

Government Scheme Finder is a web application that helps users discover relevant government schemes based on their eligibility and needs. Built with React, Vite, and Node.js, it provides scheme search, eligibility checking, and AI-powered assistance to make government benefits easier to find and understand.

**Live Demo:** https://scheme-finder-lgnm.onrender.com

**Tech Stack:** React, Vite, Node.js, Express, SQLite, and AI integration.
